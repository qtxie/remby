# Emby Theater GUI 复刻规格

## [S1] 问题陈述

当前 Remby GUI 使用左侧固定侧边栏 + 纯黑背景 + 单张海报网格的布局，与 Emby Theater 的设计差距较大。用户希望复刻 Emby Theater 的视觉风格和交互模式。

### 颜色系统
- 背景渐变：`#1a3a5c` → `#0d2137`（深蓝渐变）
- 卡片背景：`rgba(255,255,255,0.1)`
- 文字主色：`#ffffff`
- 文字次色：`rgba(255,255,255,0.6)`
- 强调色：`#52b54b`（Emby 绿）
- 标签背景：`rgba(255,255,255,0.2)`

## [S3] 组件设计

### 3.1 Header（顶部导航栏）
- 高度：60px
- 左侧：汉堡菜单图标 + Emby Logo
- 中间：标签页（主页 / 喜欢）
- 右侧：投屏、搜索、用户、设置图标
- 背景：透明（融入渐变背景）

### 3.2 媒体库卡片
- 尺寸：140px × 120px
- 内部：4 张小海报拼贴（2×2 网格）
- 圆角：8px
- 悬停效果：放大 1.05x + 阴影

### 3.3 继续观看卡片
- 尺寸：240px × 140px（横版）
- 内容：横版缩略图
- 下方：标题 + 集数信息
- 圆角：8px
- 悬停效果：放大 + 播放按钮覆盖

### 3.4 最新电影卡片
- 尺寸：140px × 200px（竖版海报）
- 下方：标题
- 右侧："查看全部" 链接
- 圆角：8px

## [S4] 导航系统

### 顶部标签页
- "主页"：显示所有内容行
- "喜欢"：显示收藏内容
- 选中状态：背景高亮

### 汉堡菜单（可选）
- 点击展开侧边抽屉
- 显示所有媒体库列表
- 用于快速跳转到特定库

## [S5] 交互效果

- 卡片悬停：放大 + 阴影 + 播放按钮（继续观看）
- 标签切换：淡入淡出过渡
- 滚动：水平滚动行支持鼠标滚轮
- 键盘：左右箭头切换选中项

## [S6] 实现阶段

| 阶段 | 内容 | 依赖 |
