# 首页修复计划

## 问题诊断

### 问题 1: "我的媒体"不显示
- `load_libraries_data` 只在 `View::Libraries` 渲染时调用（app.rs:1125-1135）
- `View::Home` 渲染时不调用 `load_libraries_data`
- 导致 `libraries` 始终为空，"我的媒体"部分不渲染

### 问题 2: Header 图标可能不显示
- 代码中确实有 Globe/Search/User/Settings 图标（app.rs:1307-1355）
- 需要验证是否正确渲染

## 修复方案

### Task 1: 首页加载时获取媒体库数据

**修改文件:** `crates/remby-gui/src/app.rs`

在 `View::Home` 的渲染逻辑中添加 `load_libraries_data` 调用：

```rust
View::Home => {
    let this = cx.entity();
    
    // 加载媒体库数据（如果尚未加载）
    if self.state.libraries.is_empty() && !self.state.loading {
        cx.spawn({
            let this = this.clone();
            async move |_window, cx| {
                cx.update_entity(&this, |app, cx| {
                    app.load_libraries_data(cx);
                });
            }
        })
        .detach();
    }
    
    HomeView::new(this.downgrade()).into_any_element()
}
```

### Task 2: 验证 Header 图标渲染

检查 Header 图标的渲染代码，确保：
1. 图标在视口内可见
2. 没有被其他元素遮挡
3. 颜色对比度足够

### Task 3: 确保加载顺序正确

`load_home_data` 和 `load_libraries_data` 应该同时调用，而不是串行：

```rust
// 在登录成功后同时加载
app.load_home_data(cx);
app.load_libraries_data(cx);
```
